Linear Regression

Supervised Tabular

Fits a linear relationship between one or more input features and a continuous output by minimizing the sum of squared errors (least squares). The model learns weights (coefficients) for each feature.

  • Sales forecasting from ad spend
  • Risk scoring in insurance

Decision Trees

Supervised Tabular

Partitions data recursively using feature thresholds to create a tree of if-else decision nodes, ending at leaf nodes that predict the output. Splits are chosen to maximize information gain or minimize Gini impurity.

Sorting Fruits with a Decision Tree
Devaraj, V. — Indiana Wesleyan University · Kaggle Fruits Dataset

Because raw image pixels cannot be read directly by a Decision Tree, each fruit image is first converted into a compact table of measurable attributes. The tree then asks a series of if-then questions on those attributes to classify 5 fruit classes: apple, banana, grape, mango, strawberry.

🔬 Key Discriminating Attributes

Attribute / Feature How It Is Measured Why It Helps
Dominant hue Avg. color of fruit region (red, yellow, green, purple) Banana → yellow; strawberry → red; grape → purple
Color saturation & brightness Avg. HSV saturation & value of fruit region Separates vivid ripe fruit from dull or shaded fruit
Aspect ratio Bounding-box width ÷ height of fruit Banana is elongated; apple & grape are rounder
Relative fruit area Fruit pixel count ÷ total image area Zoomed vs. wide-angle shots produce different scales
Contour smoothness Perimeter² ÷ (4π × area) Grapes cluster in bunches → jagged edges; apple → smooth

Random Forest

Supervised Tabular

An ensemble of decision trees each trained on a random bootstrap sample with a random feature subset. Predictions are aggregated via majority vote (classification) or averaging (regression), reducing overfitting.

⚡ How It Works

→

🌍 Real-World Use Cases

  • Fraud detection in banking
  • Patient risk stratification
  • Feature importance in EDA

Gradient Boosting

Supervised Tabular

Sequentially builds weak learners (shallow trees) where each new tree corrects the residual errors of its predecessors by descending gradient of a loss function. XGBoost and LightGBM are optimized implementations.

⚡ How It Works

→
Add Weak Learner
→
Repeat → Ensemble

🌍 Real-World Use Cases

  • Kaggle competition winning models
  • Click-through rate prediction (ads)
  • Supply chain demand forecasting

Support Vector Machine

Supervised Tabular

Finds the optimal hyperplane that maximizes the margin between two classes. Kernel tricks (RBF, polynomial) allow non-linear separation by mapping data to higher-dimensional spaces.

K-Means Clustering

Unsupervised Tabular

Partitions data into K clusters by iteratively assigning each point to the nearest centroid and updating centroids to the cluster mean until convergence. Minimizes within-cluster variance.

⚡ How It Works

→

  • Customer segmentation in retail
  • Document topic grouping
  • Image color quantization

Principal Component Analysis

Unsupervised Tabular

Reduces dimensionality by finding orthogonal axes (principal components) that capture maximum variance in the data via eigenvalue decomposition of the covariance matrix.

Convolutional Neural Network

Supervised Computer Vision

Uses learnable convolutional filters to automatically detect spatial hierarchies of features (edges → textures → objects) from images. Pooling layers reduce spatial dimensions and build translation invariance.

⚡ How It Works

→

🌍 Real-World Use Cases

  • Object detection (YOLO, Faster R-CNN)
  • Medical image diagnosis (X-ray, MRI)

Generative Adversarial Network

Unsupervised Generative AI Computer Vision

A Generator network creates synthetic data (images, audio) to fool a Discriminator network that tries to distinguish real vs. fake. The two compete in a minimax game until the generator produces realistic outputs.

Diffusion Models

Unsupervised Generative AI Computer Vision

Learns to generate images by reversing a gradual noising process. A neural network (U-Net) is trained to denoise images step-by-step. During inference, random noise is iteratively refined into coherent images.

⚡ How It Works

→
Learn Denoise
→
Generate (Reverse)

🌍 Real-World Use Cases

  • Stable Diffusion — text-to-image generation
  • DALL-E 3 / Midjourney image synthesis
  • Drug molecule design in biotech
